# Market Combat API

Договор между приложением и сервером. Сейчас его выполняет заглушка внутри приложения (`src/mock-server`). Потом его же выполнит сервер на Go по адресу `https://api.ahilespelid.ru`. Типы описаны в `src/api/contract.ts`, этот файл — их человеческая версия.

## Общие правила

- Формат — JSON по HTTPS. Авторизация: заголовок `Authorization: Bearer <token>`.
- Суммы указываются в целых ABIE (валюты игр — в целых единицах своей валюты), время — в миллисекундах Unix.
- Ошибка возвращается так: `{ "error": { "code": "...", "message": "..." } }`.
- Заголовок `X-Region` — регион устройства. Это слабая подсказка для страны нового кабинета, когда ещё не известны ни телефон, ни платёж.

| Код ошибки | HTTP | Когда |
|---|---|---|
| `unauthorized` | 401 | нет сессии или она истекла |
| `invalid_input` | 400 | неверные данные в запросе |
| `invalid_code` | 400 | неверный код из письма |
| `challenge_expired` | 410 | попытка входа истекла или уже использована |
| `insufficient_funds` | 409 | не хватает ABIE |
| `rate_limited` | 429 | слишком часто |
| `not_found` | 404 | нет такого объекта |
| `forbidden` | 403 | действие запрещено (например, игра чужой вселенной) |
| `payment_required` | 402 | платная игра ещё не открыта: сначала оплатите вход |
| `identity_conflict` | 409 | идентификаторы входа принадлежат разным кабинетам: один идентификатор — один кабинет |
| `conflict` | 409 | состояние не позволяет (например, персонаж не выбран) |
| `network` | — | только в приложении: запрос не дошёл до сервера |

## Вход

| Запрос | Тело | Ответ |
|---|---|---|
| `POST /v1/auth/email/start` | `{ email }` | `{ challengeId, expiresAt }`. На почту уходит код из 6 цифр, он действует 10 минут. Повторная отправка возможна не раньше чем через 30 с. |
| `POST /v1/auth/email/verify` | `{ challengeId, code }` | `AuthResult`. После 5 неверных кодов попытка сгорает. |
| `POST /v1/auth/telegram/start` | `{}` | `{ challengeId, expiresAt, botUrl }`. Ссылка открывает бота с одноразовым параметром `start=login_…`. |
| `POST /v1/auth/phone/start` | `{}` | То же, но `start=phone_…`: бот просит поделиться номером телефона (бесплатно, без SMS). |
| `GET /v1/auth/challenges/{id}` | — | `{ status: "pending" }`, `{ status: "expired" }` или `{ status: "confirmed", ...AuthResult }`. Подтверждённый вход отдаётся один раз. |
| `POST /v1/auth/google` | `{ idToken }` | `AuthResult`. Сервер проверяет Google ID token. |
| `POST /v1/auth/logout` | `{}` | `{ ok: true }` |

`AuthResult = { session: { token, expiresAt }, account, profile, isNew }`. Сессия действует 30 дней. Первый вход с новым способом создаёт аккаунт, профиль и кошелёк, на который зачисляется 100 ABIE.

Как бот подтверждает вход на настоящем сервере: Telegram присылает на webhook сервера сообщение `/start login_<nonce>` или контакт игрока. Сервер находит попытку по `nonce` и привязывает Telegram id или номер телефона. В заглушке это делает `server.dev.telegramConfirm`.

## Профиль

| Запрос | Тело | Ответ |
|---|---|---|
| `GET /v1/me` | — | `{ account, profile }` |
| `PATCH /v1/me/profile` | `{ nickname? }` | `Profile`. Ник — от 2 до 16 символов. |

`Profile = { accountId, nickname, character, inUniverse, country, gender, genderChangedAt, skins, stats, respect }`. Пока персонаж не выбран, `character` и `gender` равны `null`. `inUniverse` — игрок внутри своей вселенной (`false` — в нейтральном кабинете). `country = { code, currency, source, fixedAt }` — страна регистрации.

## Страна и цена ABIE

- 1 ABIE = 1 единица денег страны регистрации: 100 ₽ дают 100 ABIE, 100 ₸ — 100 ABIE, $100 — 100 ABIE. Пересчёта между валютами нет.
- Страна фиксируется один раз, при регистрации кабинета, и больше не меняется. Источники по силе: страна платёжной карты, страна номера телефона, регион устройства (`X-Region`). `source` показывает, по какому признаку она зафиксирована.
- Если признаки расходятся (номер или карта другой страны, сеть другой страны, VPN), предлагается самая дорогая валюта из участвующих; при VPN — доллар. Справочные курсы `REFERENCE_USD` (`src/wallet/countries.ts`) нужны только чтобы понять, какая валюта дороже; ABIE через них не пересчитываются.

| Запрос | Тело | Ответ |
|---|---|---|
| `POST /v1/abie/quote` | `{ abie, payment?, network?, vpn? }` | `{ currency, price, mismatch, considered, home }`. Цена `abie` ABIE. На сервере Go `payment`, `network` и `vpn` приходят от платёжного провайдера и из самого запроса; заглушка берёт их из тела. Настоящих платежей пока нет: это механика. |

Один идентификатор — один кабинет. Если при входе через Telegram-бота номер телефона и аккаунт Telegram уже принадлежат разным кабинетам, вход отклоняется (`refused`, `identity_conflict`): войдите в свой кабинет или зарегистрируйте новый с другим номером или почтой. Новые идентификаторы того же человека привязываются к его кабинету.

## Персонаж и внешность

Персонажи: `waldberik`, `ozonik`, `avitos`, `yandos` (старый id `valdberik` читается как `waldberik`). Пол: `m`, `f`. В `skins` лежит коллекция скинов игрока: 4 бесплатных персонажа есть у всех с самого начала, новые скины будут добавляться туда же.

| Запрос | Тело | Ответ |
|---|---|---|
| `POST /v1/me/character` | `{ character, gender }` | `Profile`. Первый выбор, бесплатно. 409 `conflict`, если персонаж уже выбран. 403, если скина нет в коллекции. |
| `POST /v1/me/character/change` | `{ character, requestId }` | `{ profile, tx }`. Переход в другую вселенную: списывает 5 000 ABIE (операция `character_change`), статистика, рейтинги, история и ABIE сохраняются. Работает и из нейтрального кабинета; игрок оказывается в новой вселенной. 409 `insufficient_funds`, если не хватает. Повтор с тем же `requestId` возвращает тот же результат и не списывает второй раз. |
| `POST /v1/me/universe/leave` | — | `Profile`. Выход в нейтральный кабинет, бесплатно. Персонаж и статус сохраняются, играть нельзя. |
| `POST /v1/me/universe/return` | `{ requestId }` | `{ profile, tx }`. Возврат в свою вселенную: 50 ABIE (операция `universe_return`), один раз на `requestId`. |
| `POST /v1/me/gender` | `{ gender }` | `Profile`. Бесплатно, не чаще раза в неделю (`genderChangedAt` — время последней смены). Раньше срока — 429 `rate_limited`. Первый выбор пола вместе с персонажем в лимит не входит. |

## Кошелёк ABIE

Отдельный сервис со своей базой (`abie_wallet`). Каждая операция имеет уникальный `id`: повтор с тем же `id` ничего не меняет, уйти в минус нельзя, история только дописывается.

| Запрос | Ответ |
|---|---|
| `GET /v1/wallet` | `{ currency: "ABIE", balance }` |
| `GET /v1/wallet/transactions?limit=20&cursor=` | `{ items: WalletTx[], nextCursor }`, новые сверху |

`WalletTx = { id, ts, kind, amount, balanceAfter, ref? }`. Виды операций `kind`:

| kind | Что это |
|---|---|
| `welcome` | приветственный бонус |
| `match_reward` | приз за место (старые матчи; призов больше нет) |
| `character_change` | смена персонажа |
| `currency_buy` | игрок купил валюту игры за ABIE |
| `currency_return` | валюта игры вернулась в ABIE после матча |
| `currency_sale`, `currency_payout` | те же две операции со стороны счёта платформы |
| `entry_buy` | игрок оплатил вход в платную игру |
| `entry_fee`, `entry_income` | 10% от входа платформе и остальное автору игры |
| `author_share` | доля автора с покупки валюты его игры |
| `kombat_boost` | пакет ускорения энергии в Market Kombat |
| `universe_return` | возврат из нейтрального кабинета в свою вселенную |
| `deposit` | покупка ABIE за деньги (появится с настоящими платежами) |
| `test_grant` | тестовые ABIE из панели разработчика |

Счёт платформы (`platform`) — обычный счёт в том же кошельке. Туда приходят ABIE, потраченные на валюты игр, и оттуда выплачивается то, что возвращается из матчей. Только этот счёт может уйти в минус: это значит, что игроки выиграли у платформы больше, чем она получила.

## Игры и их валюты

Реестр игр хранится на сервере. Запись появляется, когда игру загружают на платформу, и после этого не меняется никогда. Запроса на изменение игры в API нет.

`GameEntry = { id, title?, universes, currency, entry, author, authorShare, publishedAt }`:
- `universes` — список вселенных (персонажей), в которых видна игра, или `"all"` для общей игры;
- `currency` — своя валюта игры или `null`: `{ code, rate: { abie, units }, settle }`;
- `entry` — вход: `{ kind: "free" }` или `{ kind: "paid", price }` (цена в ABIE, платится один раз, после этого игра открыта навсегда);
- `author` — автор идеи `{ accountId, nickname }` или `null` для игр платформы; `authorShare` — процент автора с каждой покупки валюты игры.

Правила валют:
- Валюта игры покупается только за ABIE.
- Курс — целые числа: `abie` ABIE покупают `units` единиц валюты. Покупка идёт целыми порциями по курсу. Курс задаётся один раз при загрузке игры и не меняется никогда.
- Потраченные ABIE уходят на счёт платформы.
- `settle: "match"` — после матча всё, что вернул матч, пересчитывается обратно в ABIE по тому же курсу. С прибыли платформа берёт 10% (округление вверх до целой единицы валюты), с убытка ничего. Сумма в ABIE округляется до целого по обычным правилам.
- `settle: "none"` — валюта остаётся в игре. Общего обратного обмена валюты игры на ABIE пока нет: решим позже.

| Запрос | Тело | Ответ |
|---|---|---|
| `GET /v1/games` | — | `{ items: GameEntry[], opened: string[] }` (`opened` — платные игры, которые игрок уже открыл) |
| `POST /v1/games/{id}/entry` | `{ requestId }` | `{ game, tx }`. Оплата входа в платную игру: 10% платформе (округление вверх), остальное автору. Платится один раз. |
| `GET /v1/games/{id}/currency` | — | `{ game, code, balance }` |
| `POST /v1/games/{id}/currency/buy` | `{ lots, requestId }` | `{ tx, currency }`. Списывает `lots × abie` ABIE, начисляет `lots × units`. Повтор с тем же `requestId` ничего не меняет. 409 `insufficient_funds`, если не хватает ABIE; 409 `conflict`, если персонаж не выбран; 403, если игра не из вселенной игрока. |

- Если у игры есть автор, с каждой покупки валюты он получает `authorShare` процентов (округление вниз), остальное — платформе.

«Дуэль на графике»: общая игра (`"all"`), торговля в деньгах страны игрока: код `LOCAL`, курс 1 ABIE = 100 единиц, где единица — сотая доля (копейка, тийин, цент), то есть 1 ABIE = 1 ₽ / 1 ₸ / $1. `settle: "match"`. Платформенные игры заглушки до запуска сервера Go могут переиздаваться с новой ревизией (`PLATFORM_REVISIONS`); авторские игры не меняются никогда.
Market Kombat: общая игра, валюта — фишки боя `KMB`, курс 1 ABIE = 10 KMB, `settle: "match"`.

На сервере Go в Percona неизменность записи держит сама база: схема и триггер — в `docs/db/games.sql`.

## Матчи

| Запрос | Тело | Ответ |
|---|---|---|
| `POST /v1/matches` | `{ game, stakeLots, requestId }` | `{ matchId, game, seed, startedAt, stake, stakeLots, tx }`. Seed выбирает сервер. Для игры с валютой ставка — `stakeLots` целых порций курса. Недостающая валюта покупается за ABIE в той же операции (`tx`). Повтор с тем же `requestId` возвращает тот же матч и ничего не списывает. |
| `POST /v1/matches/{id}/finish` | `{ place, equity, actions, endTick? }` | `{ matchId, place, stake, equity, profit, fee, payout, net, tx, profile }`. Повтор возвращает тот же ответ, ничего не выплачивается второй раз. |

- Без выбранного персонажа играть нельзя (409 `conflict`). Игра чужой вселенной — 403.
- Призов за места нет: игрок торгует на свои. `equity` — его баланс в валюте игры в конце. `profit = equity − stake`, `fee` — 10% прибыли, `payout` — сколько ABIE вернулось, `net` — итог в ABIE с учётом ставки.
- Если матч не завершили (закрыли приложение, сел телефон), через 3 минуты 3 секунды после начала сервер сам закрывает его и возвращает ставку целиком, без комиссии. В статистику такой матч не идёт.
- `endTick` — тик, на котором игрок закончил (гонг или выход раньше). Сервер хранит `actions` и `endTick` для истории: по `seed` и действиям матч проигрывается заново целиком, со сделками всех трейдеров. Неправильные действия отбрасываются.
- Сейчас сервер доверяет `place` и `equity`. На следующем шаге он сам проиграет матч по `seed` и `actions` и вычислит итог. Тогда же закроется лазейка «закрыть приложение, когда проигрываешь»: сейчас такой матч возвращает ставку.

## Предложения игр и оферта

Автор присылает идею, а не код: одобренные игры платформа делает сама. Песочницы для чужого кода нет.

| Запрос | Тело | Ответ |
|---|---|---|
| `GET /v1/offer?lang=ru` | — | `{ version, draft, title, paragraphs }`. Сейчас это черновик (`draft: true`): текст должен проверить юрист. Есть на английском и русском, языки СНГ получают русский. |
| `POST /v1/proposals` | `{ title, description, universes, currency, entry, offerVersion, requestId }` | `Proposal`. `currency = { code, rate: { abie, units }, authorShare } \| null`, `entry` — как у игры. 409 `conflict`, если принята не текущая версия оферты. |
| `GET /v1/proposals` | — | `{ items: Proposal[] }`, свои, новые сверху |
| `GET /v1/proposals/{id}` | — | `Proposal` с перепиской |
| `POST /v1/proposals/{id}/messages` | `{ text }` | `Proposal` |
| `PUT /v1/proposals/{id}` | черновик | `Proposal`. Только когда модератор попросил правки; заявка возвращается на рассмотрение. |

Статусы: `review` (на рассмотрении), `changes_requested` (нужны правки), `approved` (одобрена), `rejected` (отклонена). Решение принимает модератор: на сервере Go это отдельный маршрут только для модераторов, в заглушке — `server.dev.moderate` (панель разработчика → «Заявки: модерация»). Одобрение записывает игру в реестр со вселенными, валютой, курсом, входом и долей автора из заявки, и после этого они не меняются. Валюта авторской игры обратно в ABIE не меняется (`settle: "none"`). Игра появляется в меню, когда мы её сделаем.

## Market Kombat

Пошаговые карточные бои персонажей вселенных. Правила — `src/game/kombat.ts`, одни и те же на сервере и в приложении. Числа — заглушки до балансировки.

**Колода.** У каждого бойца своя колода из 53 карт, перемешанная по seed боя: четыре масти (масть = вселенная: `waldberik`, `ozonik`, `avitos`, `yandos`) по 13 карт и джокер. Карта — строка `"<масть>-<номинал>"` (`ozonik-7`, `yandos-A`) или `"joker"`. В руке 5 карт; за ход разыгрывается одна, вместо неё из колоды приходит новая.

| Номинал | Карта | Цена, энергия |
|---|---|---|
| 2, 4, 6, 8, 10 | атака: урон 6 / 9 / 12 / 15 / 18 | 0 / 5 / 10 / 15 / 20 |
| 3, 5, 7, 9 | защита на этот ход: гасит 6 / 10 / 14 / 16; 9 ещё и отвечает ударом 6 тому, кто атаковал | 0 / 5 / 10 / 15 |
| J | разгон: +2 к комбо; если в этот ход пропустил удар — комбо сгорает, а удар на 25% сильнее | 10 |
| Q | Валдберик, Авитос: щит 10 на 2 хода; Озоник, Яндос: лечение 18 | 20 |
| K | хитрость масти (если удар прошёл): Валдберик — урон 8 и оглушение (соперник пропускает следующий ход, дважды подряд нельзя); Озоник — урон 6 и яд 5 на 3 хода (яд идёт сквозь защиту); Авитос — урон 8 и кража 20 энергии; Яндос — урон 14 сквозь любую защиту | 30 |
| A | суперудар вселенной: «Лавина посылок» 30; «Робот-упаковщик» 22 и лечение 12; «Жёсткий торг» 20 и кража 25 энергии; «Умный маршрут» 24 сквозь защиту | 40 |
| джокер | становится любой картой, которую назовёт игрок (`as`), и стоит как она | — |

- Карты своей вселенной сильнее на 25% (урон, защита, лечение, щит, яд, кража, ответный удар; округление до целого).
- Две карты одной масти подряд дают +1 к комбо (до 4). Атака тратит комбо: +25% за уровень. Передышка и пропущенный ход разрывают цепочку масти, но комбо не сбрасывают.
- Крит: 10%, урон ×1,5.
- Энергия: старт 30, до 100, +10 за ход (с ускорением +20).
- Вместо карты можно взять передышку (`rest`): +15 энергии сверх обычных, и по желанию одна карта руки меняется на новую (`discard`). Какая карта сброшена, сопернику не показывается.
- Оба выбирают одновременно, на ход 20 секунд, чужая рука и чужой выбор не видны. Когда выбрали оба или вышло время, сервер разыгрывает ход; кто не выбрал — пропускает ход (`timeout`). Оглушённый пропускает ход сразу, его не ждут.
- Бой до нокаута или 20 ходов (тогда побеждает тот, у кого больше здоровья; поровну — ничья). Если оба упали в один ход, побеждает тот, кто упал меньше.

`KombatView`: `{ id, mode, status, rules, you, fighters, turn, maxTurns, turnMs, deadline, serverNow, createdAt, startedAt, finishedAt, hand, myPlay, log, stake, stakeLots, settlement }`.
- `hand` — свои карты; руки соперника в ответе нет, только `handSize` и `deckSize` у бойца.
- У бойца: `hp`, `energy`, `combo`, `boosted`, `effects` (действующие эффекты: `{ kind: "shield" | "poison" | "stun", amount, turns }`), `lastSuit` (масть прошлой карты).
- `log` — все сыгранные ходы по порядку: `{ turn, at, sides: [сторона, сторона] }`. У стороны: что сыграно (`play`: карта, джокер с выбором, передышка, оглушение, время вышло), карта по факту, цена, своя масть, цепочка, потраченное комбо, урон до и после защиты, крит, погашено, ответный удар, яд, лечение, украденная энергия, сорванный разгон, наложенные эффекты, весь полученный урон и снимок после хода (здоровье, энергия, комбо, эффекты). По `log` приложение показывает ход боя, график здоровья и повтор.
- `rules` — версия правил. Бои старых правил (до карт) заглушка один раз удалила, ставки ожидавших и шедших боёв вернула.

| `GET /v1/kombat/boost` | — | `{ fightsLeft }` |
| `POST /v1/kombat/boost` | `{ pack, requestId }` | `{ tx, boost }`. Пакеты ускорения энергии: на 1 бой — 500 ABIE, на 5 боёв — 2 000 ABIE (цены-заглушки, подберём на балансе). Расходуется по одному на каждый бой с игроком; тренировка пакет не тратит. |

Расчёт боя с игроком: победитель забирает обе ставки, платформа берёт 10% выигрыша (то есть ставки соперника, округление вверх), фишки возвращаются в ABIE. Проигравший теряет ставку. Ничья — ставки возвращаются без комиссии. Бой с компьютером денег не двигает, поэтому «фармить» ботов бессмысленно.

Панель разработчика: «Тестовый соперник для боёв с игроками» — заглушка сама подставляет соперника через 1,5 секунды, чтобы бой с игроком можно было проверить на одном телефоне. У соперника свой счёт ABIE.

## История игр

Сыгранные матчи «Дуэли на графике» и бои Market Kombat игрока, новые сверху. Тренировки тоже здесь.

| Запрос | Тело | Ответ |
|---|---|---|
| `GET /v1/history?game=&cursor=&limit=` | — | `{ items: HistoryItem[], next }`. `game` — одна игра (`duel`, `kombat`) или все; по 20, до 50. |
| `GET /v1/history/{id}` | — | `{ item, duel?, kombat? }`. Чужое — 404. |

- `HistoryItem = { id, game, startedAt, finishedAt, outcome, place, players, mode, opponent, turns, stake, net }`. `outcome`: `win`, `loss`, `draw`, `cancelled` (бой, к которому никто не пришёл), `abandoned` (матч, закрытый сервером). `net` — итог в ABIE: вернулось минус поставлено.
- Дуэль: `duel = { replayable, seed, stake, nickname, actions, endTick, equity, place, fee, payout }`. `replayable: false` — матч сыгран до того, как сервер стал хранить действия, или закрыт сервером: повтора нет. Иначе приложение проигрывает матч заново (`replayDuel` в `src/game/duel.ts`): график, таблица и лента «кто что когда» в любой момент матча.
- Бой: `kombat` — полный `KombatView` с `log` всех ходов; приложение показывает ход боя, график здоровья и повтор по шагам.

В приложении: кнопка «История» на карточке каждой игры (история этой игры) и «История игр» в кошельке (все игры, с фильтром).

Лента дуэли «кто что когда» во время матча строится из `DuelState.log`: входы, выходы, ликвидации всех трейдеров, новости и закрытие по гонгу, с временем матча.
